How to find your free/busy link

Get your ICS subscription URL, then paste it into Add Availability. Links are live feeds — you generate once and share.

90d

Links show 90 days of availability

Your ICS subscription link shows calendar data for approximately the next 90 days. After that window, generate a fresh link using the steps below to keep scheduling accurate.

  1. Go to calendar.google.com and sign in
  2. In the left sidebar, hover over the calendar name — click ⋮ → Settings and sharing
  3. Scroll to the “Integrate calendar” section
  4. Copy the “Secret address in iCal format” — begins with https://calendar.google.com/calendar/ical/
  5. Paste this URL into the Subscription URL field
Keep it private. The secret address works like a password — only share it with people who need your availability. You can reset it anytime in the same Settings page.

Outlook.com (web)

  1. Go to outlook.com and open the Calendar view
  2. Click the gear icon ⚙ at top right → “View all Outlook settings”
  3. Navigate to Calendar → Shared calendars
  4. Under “Publish a calendar”, choose your calendar
  5. Set permission to “See free/busy (hide title and details)” for privacy
  6. Click Publish and copy the ICS link (not the HTML one)

Microsoft 365 / Exchange

  1. In the Outlook desktop app: File → Account Settings → Account Settings…
  2. Go to the Internet Calendars tab to find published feeds
  3. Or check with your IT admin — free/busy sharing may be configured at the org level

Mac — Calendar app

  1. Open the Calendar app on your Mac
  2. Right-click (Control-click) the calendar name in the sidebar
  3. Select “Share Calendar…”
  4. Check “Public Calendar”
  5. Click “Copy Link” — it begins with webcal://
  6. Paste as-is; the scheduler converts it automatically

iCloud.com

  1. Go to icloud.com and open Calendar
  2. Click the share icon next to your calendar name in the sidebar
  3. Enable “Public Calendar” and copy the link
Privacy tip. iCloud public links include event titles. Consider creating a separate “Availability” calendar with only the events you want visible, then sharing that calendar's link.

Export your calendar as a .ics file using the steps below, then on the Add Availability tab either select Upload .ics to pick the file directly, or open it in a text editor and use Paste ICS. Both options bypass browser security restrictions on calendar URLs.

Google Calendar

  1. Go to calendar.google.com → click the gear icon → Settings
  2. In the left sidebar, click your calendar name under “Settings for my calendars”
  3. Scroll to the bottom and click “Export calendar” — downloads a .ics.gz zip
  4. Unzip it to get the .ics file. Open in any text editor, select all (Ctrl/⌘ A), copy
  5. On Add Availability: use Upload .ics to select the file directly, or open it in a text editor, copy all, and paste using Paste ICS

Microsoft Outlook

  1. In Outlook desktop: go to File → Open & Export → Import/Export
  2. Choose “Export to a file” → “iCalendar format (.ics)”, click Next
  3. Select your calendar, choose a save location, click Finish
  4. On Add Availability: use Upload .ics to select the file directly, or open it in Notepad, copy all, and paste using Paste ICS

Apple iCloud / Mac Calendar

  1. Open the Calendar app on your Mac
  2. In the menu bar: File → Export → Export…
  3. Choose a save location and click Export — saves a .ics file
  4. On Add Availability: use Upload .ics to select the file directly, or open in TextEdit, copy all (⌘ A), and paste using Paste ICS
Large exports are fine. The scheduler automatically filters to events in the next 90 days — exporting your full calendar history won't slow things down.

URL not loading? Use “Paste ICS content” instead.

Browser security (CORS) can block external calendar URLs. As a fallback: export your calendar as a .ics file, open in any text editor, copy all the content, and paste it using the Paste ICS content option on the Add Availability tab.
